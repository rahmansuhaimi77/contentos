COMMON QUESTIONS

Before you enquire.

Can I ask for a phone that is not listed?

Yes. Use “Request a phone” and tell Tech Rilex the exact model plus any storage, colour or budget preference.

Why are some product details blank?

Because Tech Rilex only displays unit-level information when it has actually been entered and confirmed for that listing.

Can availability change?

Yes. A unit can be available, reserved or sold, so confirm the current status on WhatsApp before making a decision.

What should I check before buying?

Model, storage, colour, physical condition, battery health when available, warranty/accessories where applicable, and the current price.
